# 🔐 InfozaTech – Cyber Security Internship Projects

A collection of hands-on cybersecurity projects developed as part of the **InfozaTech Cyber Security Internship**. These projects focus on essential cybersecurity concepts such as data encryption, file integrity verification, and password security analysis.

The repository contains three practical tools designed to demonstrate fundamental cybersecurity techniques through real-world applications.

---

## 🚀 Projects Included

### 1. CyberNova – Encryption & Decryption Toolkit
**Category:** Cryptography and Data Security

CyberNova is an encryption and decryption toolkit designed to protect sensitive information by converting readable data into an encoded format and restoring it when required.

**Key Features:**
- Encrypt sensitive text and data.
- Decrypt encrypted information.
- Protect confidential information from unauthorized access.
- Demonstrate fundamental cryptographic concepts.
- User-friendly interface for encryption and decryption operations.

**Objective:** To understand cryptography and implement secure data communication techniques.

---

### 2. HashSentinel – File Integrity Checker
**Category:** File Security and Integrity Monitoring

HashSentinel is a file integrity checking tool that uses cryptographic hash functions to detect unauthorized modifications in files.

**Key Features:**
- Generate cryptographic file hashes.
- Verify file integrity using hash comparison.
- Detect unauthorized file modifications.
- Identify changes in file contents.
- Support secure file monitoring using hashing techniques.

**Objective:** To understand cryptographic hashing and ensure data integrity through file verification.

---

### 3. PassSentinel – Password Strength Analyzer
**Category:** Password Security and Authentication

PassSentinel is a password strength analyzer that evaluates password security based on different criteria and provides feedback to help users create stronger passwords.

**Key Features:**
- Analyze password strength.
- Check password length.
- Identify uppercase and lowercase letters.
- Detect numbers and special characters.
- Evaluate password complexity.
- Provide suggestions for creating stronger passwords.

**Objective:** To promote secure password practices and understand authentication security.

## ⚙️ Installation & Usage

### Step 1: Clone the Repository

```bash
git clone https://github.com/ravikantmaurya00/INFOZATECH.git
```

### Step 2: Navigate to the Repository

```bash
cd INFOZATECH
```

### Step 3: Open a Project Folder

```bash
cd CyberNova
```

### Step 4: Install Dependencies

If a project contains a `requirements.txt` file, install its dependencies using:

```bash
pip install -r requirements.txt
```

### Step 5: Run the Project

Run the appropriate Python file:

```bash
python filename.py
```

*Note: Replace `filename.py` with the actual entry-point filename of the selected project.*
